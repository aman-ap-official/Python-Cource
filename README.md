## 🌟 About This Repository

A hands-on **Python learning journey** — clean examples, practice questions, and real-world labs.
Every file is small, readable, and built to be **run and modified**, not just read.

> **Goal:** Turn Python fundamentals into practical, job-ready skills.

## 🗣️ Written in English + Hinglish

Every lesson is explained **twice**, so you never get stuck on the language:

| Language | Purpose |
| :------- | :------ |
| 🇬🇧 **English** | Clear, standard explanations for every concept |

## 🌐 Requests Lab

Learn how Python talks to the internet:

```python
import requests

response = requests.get("https://api.github.com")

print(response.status_code)
print(response.text)
```

| Status | Meaning |
| :----: | :------ |
| `200` | Success |
| `404` | Not Found |
| `500` | Server Error |

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/aman-ap-official/Python-Cource.git
cd Python-Cource
```

**2. Install dependencies** *(only for the requests lab)*

```bash
pip install requests
```

**3. Run any file**

```bash
python Variables.py
```
