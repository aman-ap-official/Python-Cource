This part is extremely important.

You wrote:

import requests

What does this mean?
English
You're telling Python:
"I want to use the code provided by the requests package in this program."

Hinglish
Aap Python ko bol rahe ho:
"Mujhe requests library ka code apne program mein use karna hai."

Think of it like:

Library installed
       ↓
   requests
       ↓
Python program
       ↓
import requests
       ↓
Now I can use it
